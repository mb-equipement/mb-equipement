# M.B. Equipement — site web

## Avant publication
1. Ouvrir `index.html`.
2. Remplacer `https://www.votredomaine.com/` par le vrai domaine.
3. Remplacer `VOTRE_EMAIL_ICI` dans le formulaire par l'adresse email professionnelle.
4. Remplacer le téléphone et l'email affichés dans la section Contact.
5. Ajouter le vrai logo M.B. Equipement si disponible.

## Pour apparaître sur Google
- Acheter un nom de domaine (ex. m b equipement .com selon disponibilité).
- Mettre ces fichiers sur un hébergeur avec HTTPS.
- Créer une propriété dans Google Search Console.
- Envoyer l'URL du site et demander l'indexation.
- Ajouter ensuite une fiche Google Business Profile avec le même nom, téléphone et adresse.

L'apparition sur Google n'est pas instantanée : Google doit d'abord explorer et indexer le site.
